# 🔮 Oráculo do Tarô & Tarefas Sagradas

Aplicativo web responsivo com o **Oráculo dos 22 Arcanos Maiores**, tiragem interativa, ritual diário e gestor de tarefas. Feito com **HTML, CSS e JavaScript puro**, sem frameworks.

🌐 **Demonstração:** https://diegorezz.github.io/dev-oraculo-tarot-app/

## ✨ Funcionalidades

- 🃏 Base de dados dos **22 Arcanos Maiores**, com significados direito e invertido, conselhos e oráculo Sim/Não
- 🎴 **Mesa de tiragem interativa**, inspirada em tarôs online
- 🌅 **Ritual diário** com sequência de dias consecutivos (streak)
- ✨ Sistema de **níveis e XP**
- 📓 **Diário cósmico** e histórico de tiragens
- ✅ **Gestor de tarefas** com filtros por status e categoria
- 👤 Cadastro e login de usuários
- 🧘 Som ambiente meditativo (drone 432 Hz)
- 📱 Layout adaptado para celular e computador

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)

## ▶️ Como executar

Não precisa instalar nada:

1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador

```bash
git clone https://github.com/diegorezz/dev-oraculo-tarot-app.git
```

## 📁 Estrutura

```
├── index.html       # Estrutura da página
├── styles.css       # Estilos e responsividade
├── app.js           # Lógica da aplicação
└── cards-data.js    # Dados dos 22 Arcanos Maiores
```

## ⚠️ Observações

Este projeto é uma **demonstração**. O login é feito no próprio navegador, sem servidor, e **não deve ser usado como sistema de autenticação seguro**. Não cadastre senhas que você usa em outros lugares.
